# Rafael Bragança Oliveira — Personal Portfolio

[![Deploy with Vercel](https://vercel.com/button)](https://rafael-braganca.vercel.app)
**Live Demo:** [https://rafael-braganca.vercel.app](https://rafael-braganca.vercel.app)

Personal portfolio website for **Rafael Bragança Oliveira**, B.Sc. Computer Science student at **ETH Zürich** and exchange alumnus at the **Technical University of Munich (TUM)**.

---

## 🌟 Features & Highlights

- **Custom WebGL Dither Shader Background**: 3-color 8x8 Bayer dithering engine built with raw WebGL (`#0d0a09`, `#792823`, `#f6eee3`).
- **Swiss Asymmetric Typography & Design System**: Custom typography featuring `@font-face` Exposure and GT Standard Light fonts.
- **Dedicated About Section**: Two-column layout highlighting academic background (Colégio Visconde de Porto Seguro, Abitur, ETH Zürich, TUM), research, tech leadership (ETH Blockchain Club, Claude Builder Club Zürich, BRASA Zurich), and 15+ years of piano performance.
- **Vertical Experience Timeline**: Chronological journey covering AI Engineering, Federated Neural Architecture Search (NAS) thesis research, and startup/community leadership.
- **Featured Projects Grid**: Live project previews for **Jasmin** (Cognition AI Top 8 Finalist) and **PersonaAI** (GenAI Lab @ TUM) in borderless dark glass cards with browser header frames.

---

## 🛠️ Technical Stack

- **Core**: Vanilla HTML5, CSS3, JavaScript (ES6+ Modules)
- **Shader Engine**: WebGL (GLSL Fragment Shaders & Bayer Matrix Dithering)
- **Build Tool**: Vite
- **Deployment**: Vercel (`rafaelbraganca.vercel.app`)

---

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/RafaelBraganca1006/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run Vite dev server locally
npm run dev
```

Build for production:
```bash
npm run build
```
